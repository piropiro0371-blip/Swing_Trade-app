# Swing_Trade-app — 日本株スイングトレード判断支援

あらかじめ決めた売買ルールを、毎日の株価に機械的に当てはめて「買い候補」「売りどき」を表示するシステムです。
ルールは過去10年のデータで検証（バックテスト）し、合格したものだけを「採用」とします。採用後も、実際の相場で前向きに成績を記録（フォワードテスト）し続けます。

**売買の発注は行いません。利益を保証するものでも、投資助言でもありません。最終判断と発注はご自身で行ってください。**

## しくみ

```
平日18:10（自動）  株価取得 → 買い候補の判定 → 台帳に記録 → フォワードテスト集計 → Web画面を更新
土曜（自動）       監視する銘柄の作り直し
随時（Claudeに指示）新しいルールの検証、資金額の変更、画面の修正
```

| 場所 | 中身 |
|---|---|
| `docs/` | Web画面（GitHub Pagesで公開）と、その表示データ |
| `src/` | データ取得・売買ルール・バックテスト・毎日の判定 |
| `config/strategy.json` | 資金額・同時保有数・採用中／検証中のルール |
| `.claude/agents/` | Claudeが作業を振り分ける担当（戦略研究・検証の監査・運用） |

## 画面の見方

- **今日の判定**: 総合判定（買い候補あり／なし／見送り）と、戦略ごとの候補銘柄
- **保有株の売り判定**: 買った銘柄を登録すると、逆指値（損切り注文）の位置と売りどきを表示。登録内容はブラウザ内だけに保存
- **フォワードテスト**: システムがその日に出したシグナルを、ルール通り売買したと仮定した成績
- **バックテスト**: 過去10年での検証結果と、5つの判定基準の合否
- **ルール**: 各戦略の買い・売りの条件

## 前提と限界

- 資金20万円・100株単位・同時に2銘柄まで（`config/strategy.json` で変更）
- コストは往復0.2%（値段のずれの見込み）。税金は未考慮
- 株価は Yahoo Finance 由来。誤り・遅れを含むことがある
- 現在上場している銘柄だけで検証しているため、成績はやや良く出る
